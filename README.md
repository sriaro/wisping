Wisping is a portable system maintenance utility for Windows 10 and 11. Wisping removes unneeded files, finds what uninstalled programs left behind, and manages startup programs, services and scheduled tasks. A disk usage analyser and a program uninstaller are included. Each feature is described below.

## Features

- **Clean**: temporary files, caches, logs, crash dumps, update downloads, broken shortcuts, browser caches, Explorer and Office history, the Recycle Bin, and the caches of desktop apps, game launchers, developer tools and AI tools. Each item says what it removes and how risky it is. Items that end sign-ins or erase history are off by default, and files from the last 24 hours are kept unless that protection is turned off.
- **Scheduled cleaning**: `Wisping.exe --clean` cleans without opening a window: the items of the last clean from the window when Remember settings is on, otherwise the default items. The report, log and history are the same as for a clean from the window, so Windows Task Scheduler can run it.
- **Registry and leftovers**: shared DLLs, app paths, uninstall entries, MUI cache, COM classes, file extensions, Open With lists and tray icons that point to nothing, and folders left behind by removed programs. Registry fixes are written to a .reg backup first; folders go to the Recycle Bin.
- **Startup**: apps that start at sign-in, scheduled tasks, right-click menu entries and services, each with a switch and a note on how safe it is to turn off. Windows items are protected and hidden by default.
- **Programs**: installed programs with size and install date. Uninstalling runs the program's own uninstaller.
- **Disk usage**: a map of what takes the space in personal files, app data or a drive, with the largest files, identical copies and the space each program uses. Looking changes nothing.
- **Tools**: switches for Game Bar, diagnostic data, error reporting and manufacturer app downloads, and resets for the notification list and tray icons. Every key is backed up before it is changed.
- **Backups**: every registry change, deleted scheduled task and removed startup file is saved first and can be restored from the Backups page. A restore point before cleaning, a log and a history of past cleanups can be turned on; they are off by default.
- **Look**: dark or light, and English or Chinese, following Windows until one is chosen.

Nothing is deleted without confirmation. Some system items need administrator rights; the sidebar has a button that restarts Wisping as administrator.

## Download

Get `Wisping-<version>-windows-x64.zip` from the [Releases page](https://github.com/sriaro/wisping/releases), unzip it anywhere and run `Wisping.exe`. There is no installer. The exe is not signed, so SmartScreen may warn the first time it runs.

## Build

Needs Windows 10 or 11, Rust 1.99 or newer and the MSVC build tools.

```
cargo build --release --locked
```

The program is `target/release/Wisping.exe`. `tools\build-release.ps1` builds the same exe for publishing, with no local paths in it. The icons and art in `ui/` and the header in `docs/` are generated by the scripts in `tools/`.

## Files and settings

- Backups, settings, cleaning reports, the log and the history are in the `data` folder beside `Wisping.exe`. When that folder cannot be used, for example because the exe is in a temporary folder, under Windows, Program Files or OneDrive, or in a read-only place, Wisping uses `%LOCALAPPDATA%\Wisping` instead. A folder chosen on the Backups page is remembered in `wisping-location.txt` beside the exe, or in `%LOCALAPPDATA%\Wisping\location.txt` when the exe folder is read-only.
- Run as administrator, Wisping keeps a few records under `HKLM\SOFTWARE\Wisping`: the original start type of services turned off from the Startup page, the original values of policies set from the Tools page, and the integrity records of backups made with administrator rights. With administrator rights, a backup can be restored only when it has such a record and is unchanged. Scheduled tasks and startup files for all users can only be restored this way.
- A restore point, when turned on, is requested from Windows System Restore before each clean or fix; Windows allows one a day.

Wisping has no background process, keeps no log unless logging is turned on, and makes no network connections.
